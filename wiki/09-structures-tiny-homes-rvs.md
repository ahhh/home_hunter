# Structures, Tiny Homes, Cabins, Yurts & RVs

[What Counts as a Home](01-what-counts-as-a-home.md) sorts accommodations into categories. This page answers a
different question: **when does a guest accommodation become a regulated building or dwelling, and what
permits does that bring?**

## The key distinctions

| | Guest brings it | Host provides, not permanent | Host provides, permanent structure |
|---|---|---|---|
| Examples | Tent, van, guest's RV | Bell tent set up each season; host RV parked on site | Cabin, yurt on a platform, tiny home, bathhouse |
| Zoning question | Camping duration / campground | Camping / campground / STR | Dwelling density, accessory structure, lodging use |
| Building permit | No | Usually no for the tent itself; **yes** for platforms/decks in most counties | **Yes** (or DOH / state where there's no building dept) |
| Hipcamp toilet tier | A-E (acreage rule) | B-E | B-E |
| Tax | Auto-camp space | Auto-camp space + shelter | Room/accommodation |

## Building code authority in Colorado

- **Colorado has no statewide building code for private residential construction.** Counties and municipalities choose whether to adopt one.
- **16 counties have no building department** (Division of Housing list, **Verified** 2026-09-29): Baca, Cheyenne, Costilla, Crowley, Custer, Delta, Dolores, Kit Carson, Mineral, Montezuma, Phillips, Prowers, Saguache, Sedgwick, Washington, Yuma.
  - In those counties **DOH** inspects and approves **foundations for manufactured homes, tiny homes and factory-built structures**. Foundation plans go to DOH.
  - Montezuma County issues no certificates of occupancy and enforces no residential building code, but **requires permits before building**.
  - Phillips County's land use code says a single-family home needs a building permit. Confirm who issues it.
- **State electrical and plumbing permits** (DORA State Electrical Board / State Plumbing Board) are required where there's no local inspection program. The state doesn't inspect where a local program exists.
- **Wildfire Resiliency Code:** new construction in WUI areas. See [Fire](08-fire-and-emergency-safety.md#wildfire-resiliency-code-new-structures).
- Counties that do adopt codes typically use the IRC/IBC. Lincoln County, for example, adopted the 2018 IRC/IBC in June 2023. **Reported.**

## Factory-built housing (DOH-regulated)

| Type | Certified by | Can be a dwelling? | Notes |
|---|---|---|---|
| HUD manufactured home | HUD | Yes | Counties can't exclude them by zoning ([C.R.S. 30-28-115](https://codes.findlaw.com/co/title-30-government-county/co-rev-st-sect-30-28-115/)). Installation must follow DOH rules. |
| Modular / factory-built | DOH | Yes | Plans to DOH or a DOH-approved third party |
| **Tiny home** ([HB22-1242](https://leg.colorado.gov/bills/hb22-1242)) | DOH | Yes. "Approved for long-term living." | Permanent chassis; permanent or temporary foundation; DOH installation rules ([8 CCR 1302-14](https://www.law.cornell.edu/regulations/colorado/8-CCR-1302-14-6)) |
| Park-model RV | ANSI A119.5 (industry) | **Generally no.** It's an RV. | Not a tiny home |
| "Tiny house on wheels" built as an RV | RVIA/NFPA 1192 | **Generally no** | Elbert: an RV "including a tiny house on wheels" is temporary |

**Verified:** DOH tiny home definitions and no-building-department list. **Reported:** the statute summary.

## Yurts, domes, canvas tents

- A **fabric structure left up for the season** on a **platform** is usually a structure. Expect a building permit for the platform and possibly the yurt (snow/wind load, egress, clearance from stoves).
- Wood stoves in yurts or tents: clearances, a spark arrestor, and a **CO alarm**.
- Chaffee's *commercial* private-lands campsites are primitive: no permanent improvements or lodging beyond water, sanitation and fire elements. A host-provided yurt there is not a "campsite". **Verified** ([Chaffee](counties/chaffee.md)).
- Gilpin says yurts, tiny homes and tents aren't permitted as permanent structures and **may not be rented out publicly**. **Verified** ([Gilpin](counties/gilpin.md)).

## Cabins

- Kitchen **and** bathroom = dwelling unit. That triggers density limits (usually 1 primary + maybe 1 ADU), OWTS sizing, and possibly an STR permit.
- A sleeping-only cabin ("bunkhouse") is still a place people sleep. Most counties **won't allow sleeping in an accessory structure** unless it's approved as a dwelling or as part of a lodging/campground approval. Fremont County allows recreational cabins only inside an approved Travel Trailer Park & Campground.
- Well water to a cabin used by paying guests: see [Water](07-water-and-wells.md). DWR treats a separate entry plus kitchen as a second dwelling.

## RVs as accommodations

- **Guest's RV:** a camping unit. County camping-duration rules apply, and paid sites may count as a campground.
- **Host-provided RV** (a "glamping" trailer): usually treated as a camping unit **and** a rental accommodation. Watch for bans on renting RVs and camping spaces as STRs ([San Miguel](counties/san-miguel.md)) or on RVs as vacation-rental accommodations ([Mesa](counties/mesa.md)). Both **Verified**. Winter use is often barred outright (Gunnison notes RVs don't meet snow-load rules).
- County RV-occupancy rules vary a lot. See the [County Matrix](counties/README.md).

## Life-safety items for any sleeping structure

| ☐ | Item | Basis |
|---|---|---|
| ☐ | **Carbon monoxide alarm** within 15 ft of sleeping areas if there's a fuel-fired appliance or attached garage | Colorado CO alarm law, [C.R.S. 38-45-101 et seq.](https://law.justia.com/codes/colorado/title-38/real-property/safety-of-real-property/article-45/) (applies to dwellings on sale/rental/renovation). **Reported.** Confirm it applies to lodging units. |
| ☐ | Smoke alarm | Building/fire code |
| ☐ | Two exits, or an egress window, in sleeping rooms | Building code |
| ☐ | Fire extinguisher | Fire code / best practice |
| ☐ | Heater/stove clearances; no unvented propane heaters indoors | Manufacturer / fire code |
| ☐ | Electrical: permitted work, GFCI outdoors | State or local electrical permit |

## Permitting pathways

| What you want | Typical path |
|---|---|
| Bare tent/RV sites, guests bring everything | Zoning approval for paid camping (by-right, admin permit, or special use) + sanitation. No building permit unless you build platforms/structures. |
| Seasonal bell tents on platforms | Above + building permit for platforms + Tier B-E toilet |
| Permanent yurts / dry cabins | Above + building permits + county approval of lodging use + CWRC in the WUI |
| Full cabins / tiny homes | Dwelling or lodging approval + building/DOH permits + OWTS + a water supply that allows the use + STR permit |
