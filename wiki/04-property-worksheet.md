# Property Compliance Worksheet: "Can I Hipcamp Here?"

Copy this page for each parcel (for example `worksheets/2026-10-chaffee-apn-12345.md`) and fill it in.
Every row gets a **status**, a **note** and a **source**. There's no plain yes/no.

| Status | Use when |
|---|---|
| **Verified** | Confirmed with the controlling agency or the adopted code text. Source and date recorded. |
| **Needs confirmation** | You have a lead (wiki page, FAQ, phone call) but nothing written or authoritative. |
| **Permit required** | Allowed, but only after a permit or approval you don't have yet. |
| **Potential conflict** | Something points to "not allowed" or "costly". Resolve it before moving forward. |
| **Not researched** | Not looked at yet. |
